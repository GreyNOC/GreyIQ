# GreyIQ wardrive — SSID patterns that CHANGE A VERDICT.
#
# Two independent jobs, distinguished by the `kind` column:
#
#   factory  — a network still broadcasting its FACTORY-DEFAULT SSID. That is a real
#              finding: the shipped SSID very often means the shipped admin password and
#              the shipped WPS PIN were never changed either, and it fingerprints the
#              exact model to anyone within radio range.
#   soft-ap  — an SSID pattern produced by a phone hotspot, a laptop soft-AP, a dev board
#              or a portable router. Not itself a defect, but in a MANAGED RF environment
#              it is an unmanaged AP, so it feeds rogue-AP triage.
#   guest    — a deliberately-open guest/captive-portal or public-hotspot network. This is
#              the FALSE-POSITIVE CONTROL for the open-network detector: an open BSS named
#              "…-guest" is an intentional design decision, so the finding is downgraded to
#              info instead of being reported as high-severity missing encryption.
#
# Matching is case-insensitive. A pattern ending in `*` is a PREFIX match; anything else
# must match the whole SSID. Patterns are matched most-specific-first (longest pattern
# wins) so `xfinitywifi` beats a bare `xfinity*`.
#
# This table is curated, not exhaustive — an SSID that is absent means "not a known
# pattern", never "safe". Vintage: 2026-07.
#
