What changes, and why

AreaTodayProposed
Layout Fixed three columns; the bot roster, the persona editor and the panel stack all compete in one rail; the transcript runs the full window width. Claude Code's three zones: a collapsible rail that is only navigation (bots, then panels), a centred transcript capped at ~46rem so lines stay readable, and a right pane that switches between the bot's record, a diff and files.
Turns Every message is the same bordered card, so the operator's question and the model's answer look alike. The operator's turn keeps a card; the assistant's prose is unboxed and reads as the page — the asymmetry is how Claude Code makes a transcript scannable.
Tool calls No equivalent. A scan or a probe arrives as prose in the stream, or not at all. A compact monospace row per call: verb, argument, result, collapsed by default and expandable to the output. This is the single biggest readability win and the piece the Studio genuinely lacks.
Composer A textarea with two rows of template chips under it, always visible. The box alone, with a status line beneath it carrying the facts that matter per prompt: live bot, provider · model, readiness, agent mode, workspace, and whether the hunt is on the offline planner. Templates move behind a key, as Claude Code does with slash commands.
Palette Blue-leaning charcoal (#1c1f23) with full-strength #ff6633. Warm near-black (#1a1917) and a slightly calmer clay accent (#e08050). The one-saturated-hue rule is kept — it is the part of the current system that works, and orange still means “this acts or is selected”.
Type IBM Plex Sans throughout; mono only inside code blocks. Unchanged families. Mono widens to carry every machine fact — tool rows, the status line, ids, paths — so prose and evidence are told apart at a glance.

One thing to decide before any of this ships

The square-edge rule is a deliberate decision, and mirroring Claude Code breaks it.

public/styles.css opens with it in writing: “SQUARE EDGES EVERYWHERE — every --radius-* is 0. A pro tool is rectangles”, plus no gradients, glows or shadows, with Burp Suite Professional named as the reference. Claude Code's GUI is softly rounded. The mockup above proposes --radius: 6px / --radius-lg: 10px, which is the single change here that overrides a documented decision rather than filling a gap. The tokens already exist precisely so this is a one-line change, and the comment says so — but it should be your one line, not a redesign that quietly drops the rule.

Toggle Current / Proposed above with the theme on both settings to judge it. Everything else in this proposal is additive or neutral; the corners are the only argument.

What it costs

  • Palette, type, status line, tool rows: public/styles.css plus markup in public/index.html. No behaviour changes, nothing to re-verify beyond looking at it.
  • Layout and the right pane: real markup restructuring in index.html and the render functions in public/app.js that write into those containers. The Workbench already has a file/diff pane, so the right zone is mostly re-homing what exists.
  • Tool rows: the only part that needs something new on the data side — the chat path would have to emit a structured record per tool call rather than prose. Worth splitting into its own change.
